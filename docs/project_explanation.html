Zero Trust SDN Project

Simple Explanation - M.Tech Research

এই প্রজেক্টটা কী?

এই প্রজেক্টে আমরা SDN (Software Defined Networking) - এ Zero Trust নামের একটা সিকিউরিটি সিস্টেম বানাচ্ছি।

সহজ ভাষায়:
যেকোনো অ্যাপ যখন SDN কন্ট্রোলারের সাথে কথা বলে, আমরা প্রতিটি কথোপকথন (request) চেক করি। কাউকে Trust করি না। সব সময় check করি।

কেন এই প্রজেক্ট দরকার?

পুরনো সিস্টেমে সমস্যা:
পুরনো SDN সিস্টেমে, একবার অ্যাপ login করলে, তারপর সে যা খুশি করতে পারত। Trust করা হতো একবার, তারপর আর check করা হতো না।

আমরা যা করি:
প্রতি request-ই ৭ বার check করি। কিছুই trust করি না!

প্রজেক্টের Main Idea

"Never Trust, Always Verify"
কাউকে বিশ্বাস করো না। সব সময় যাচাই করো।

একটা অ্যাপ যখন request পাঠায়, আমরা ৭টি স্তর চেক করি:

স্ল নংচেকের নামকী চেক করা হয়
1Token Checkটোকেন বৈধ কিনা?
2API Key CheckAPI কী ঠিক আছে?
3Device Checkডিভাইস কি নিবন্ধিত?
4RBACরোল অনুমতি দেয়?
5ABACAttributes মিলছে?
6Behavior Checkঅস্বাভাবিক আচরণ?
7Trust Scoreস্কোর কি 0.6 এর উপরে?

যদি কোনো একটি চেক fail হয় → request BLOCKED

যদি সব চেক pass হয় → request ALLOWED

প্রজেক্টের কী কী ফাইল আছে?

ফাইলকাজ
controller/trust_verification.pyমূল ইঞ্জিন - ৭টি চেক করে
controller/ryu_controller.pySDN কন্ট্রোলার
topology/network_topology.pyনেটওয়ার্ক টপোলজি
apps/legitimate_app.pyভালো অ্যাপ (Allow হবে)
apps/malicious_apps.pyখারাপ অ্যাপ (Block হবে)
tests/run_all_tests.pyসব টেস্ট চালায়

কী কী Attack simulate করেছি?

৫ ধরনের Attack:
1. Unauthorized Access - কোনো টোকেন ছাড়া access চাচ্ছে → BLOCKED
2. Fake Application - নিজেকে legitimate বলে মিথ্যা বলছে → BLOCKED
3. Compromised App - হঠাৎ অনেক request পাঠাচ্ছে → BLOCKED
4. Replay Attack - পুরনো টোকেন পুনরায় use করছে → BLOCKED
5. Unauthorized API - অনুমতি ছাড়া কিছু করতে চাইছে → BLOCKED
ফলাফল:
✅ সব ৫টি attack BLOCKED হয়েছে!
✅ ভালো অ্যাপের সব request ALLOWED হয়েছে!
✅ গড় latency: 0.21 ms (খুব দ্রুত)

কীভাবে নিজের machine এ run করবে?

Step 1: Ubuntu install করো
Step 2: এই command গুলো run করো:
sudo apt-get install -y mininet
sudo pip3 install ryu
Step 3: কন্ট্রোলার run করো:
ryu-manager controller/ryu_controller.py
Step 4: আরেক টার্মিনালে টপোলজি run করো:
sudo python3 topology/network_topology.py
Step 5: টেস্ট run করো:
python3 tests/run_all_tests.py

IEEE Paper এর জন্য কী দরকার?
